PLAYORA Dashboard

Cara menjalankan:
1. Ekstrak PLAYORA_Dashboard.zip.
2. Pastikan index.html dan folder assets berada dalam satu folder.
3. Klik dua kali index.html atau buka melalui Chrome/Edge.

Fitur frontend demo: navigasi, pencarian game/berita, slider banner, favorit visual, tab komunitas, like, bookmark, modal masuk/daftar, dropdown profil, dan notifikasi.

Catatan: login/daftar, komentar, data turnamen, serta penyimpanan favorit belum terhubung ke backend/database. Form login hanya validasi browser.
